연말대회 HTML 사용 방법

1. 연말대회.html 파일을 Chrome 또는 Edge에서 더블 클릭하여 엽니다.
2. 미스터리 사인이 처음 표시됩니다. 스테이터스 버튼으로 참가자를 추가하세요.
3. 화면의 결! 합!, 미스터리 사인, 스테이터스 링크로 화면을 열 수 있습니다.
4. 같은 HTML 파일을 같은 브라우저에서 열면 플레이어 이름·사진·점수·탈락 상태와 게임 진행을 공유합니다.
5. 참가자와 진행 상황은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 저장 데이터를 지우면 초기화됩니다.
6. 파일을 다른 위치에 복사하거나 다른 브라우저·기기에서 열면 기존 데이터가 공유되지 않을 수 있습니다.
7. 웹에 배포한 사이트와 로컬 HTML의 저장 데이터는 서로 별개입니다.
8. 기존 게임은 인터넷 연결 없이 실행됩니다. 모바일 손들기는 웹 배포와 인터넷 연결이 필요합니다.
9. GitHub Pages에는 같은 폴더의 index.html과 hand-config.json을 올립니다. 게임의 모바일 손들기에서 참가 링크를 만들고 휴대폰에 공유하세요.
10. 손들기 서버 최초 설정 방법은 프로젝트의 docs/HAND-RAISE-SETUP.md를 참고하세요.
11. 두 게임의 결과 화면에서 다시 플레이/다시 시작을 누르면 누적 점수를 유지하고 해당 게임의 메인 화면으로 돌아갑니다.
12. 스테이터스의 전체 리셋은 확인 후 참가자·사진·점수·탈락·되돌리기 기록·두 게임 진행을 모두 초기화합니다. 되돌릴 수 없습니다.
13. 전체 리셋은 같은 브라우저의 열린 화면을 새로고침하고, 해당 진행자의 손들기 방을 종료합니다. 휴대폰에는 새 참가 링크로 다시 입장하라는 안내가 표시됩니다. 방 종료 실패 시 오류를 표시하므로 연결을 확인하고 다시 시도하세요.
14. 업데이트 후 기존에 열어둔 화면은 한 번 새로고침해 최신 버전을 적용하세요.

주소 끝의 화면 선택값:
#mystery-sign : 미스터리 사인
#gyeol-hap : 결! 합!
#status : 스테이터스
#hand-raise?room=방ID : 휴대폰 손들기 (진행자가 공유한 링크 사용)

브라우저가 파일 저장소를 제한하여 저장 오류가 표시되면 일반 Chrome/Edge 창으로 열어 주세요.
