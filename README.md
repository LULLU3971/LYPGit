# 연말대회

결! 합!, 미스터리 사인, 스테이터스와 모바일 손들기를 제공하는 정적 웹입니다.

## 사용 순서

1. 배포된 사이트의 스테이터스에서 참가자를 등록합니다.
2. 진행할 게임을 열고 모바일 손들기의 참가 링크를 만듭니다.
3. 참가자는 휴대폰으로 공유된 링크에 들어가 등록된 이름을 입력합니다.
4. 진행자가 게임을 시작하면 가운데 버튼으로 손을 들 수 있습니다.

진행자 화면의 참가자·점수·게임 진행은 해당 브라우저에 저장됩니다. 다른 주소나 브라우저의 기존 데이터는 자동으로 옮겨지지 않습니다. 손들기는 Supabase를 통해 실시간으로 처리됩니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다. `index.html`에 JavaScript, CSS와 이미지가 포함돼 있어 별도 빌드 서버가 필요하지 않습니다. `.nojekyll`은 정적 파일을 그대로 제공합니다.

화면 주소 끝의 선택값:

- `#status`: 스테이터스
- `#gyeol-hap`: 결! 합!
- `#mystery-sign`: 미스터리 사인
- `#hand-raise?room=방ID`: 참가자용 손들기 화면

`hand-config.json`에는 브라우저에서 사용하는 Supabase 공개 설정만 들어 있습니다. 데이터 접근과 손들기 순서는 Supabase 데이터베이스 권한 및 서버 함수에서 검증합니다.
